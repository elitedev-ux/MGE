# Product catalogue review

81 supplied files mapped to 76 catalogue entries. Original files are unchanged. Exact duplicate image bytes are not repeated in galleries. Alternate packaging images are grouped where the label and product match.

## Editing prices and stock

Edit `price` in `client/src/data.ts`; all values are dummy NGN prices authorised by the owner. Set `priceIsPlaceholder` to false only after replacing a demo price. Stock is null (unknown), not a fictional stock count. The preview bag allows up to 99 units when stock is unknown. Set stock to the actual quantity when available. Do not rerun the import script after editing the catalogue: it is a one-time seed.

## Evidence and limitations

Product images establish visible labels and appearance, not authenticity, warranty, condition, or exact internal specifications. Packaging-only ratings are labelled as claims. Laptop model numbers, CPU, RAM, SSD, screen specifications, and condition remain unconfirmed. No standalone phone image was provided; the phone carousel illustration remains, with its links directed to accessories.

The LIVE 85NC, K11, ear-hook JBL-labelled earbuds, MG-S20, 35W Apple-style bundle, and unidentified Bose headset require model confirmation. The Q41 package reads G41 but its OPB-7401Q code corresponds to oraimo Q41. ZEALOT model references have conflicting or uncertain details, so unsupported runtime, battery, and waterproofing claims are omitted.
